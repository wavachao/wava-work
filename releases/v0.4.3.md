## 发布概述

Wava Work 首次正式稳定发布。此版本在 v0.4.2 源码基础上建立可追踪的版本发布流程，保留模块化工作流与个人偏好。适用于 Codex、Claude Code 等支持 Agent Skills 的客户端。

## 主要能力

- 按需加载代码、UI、文档、图表、PPT 和视频模块；入口避免累积全部任务指令。
- Python 项目默认使用 uv，依据依赖与协调成本组织 subagent 和 Git worktree。
- 固定字体偏好，并优先采用现有工具和专用格式技能。
- 技能清单支持独立登记与扩展；默认从官方上游安装最新核心 Ponytail。
- 通过可核查反馈进行最小规则修改，保留验证记录和回退依据。
- Git 提交使用单行 Conventional Commits；CI 检查完整提交历史。

## 本次变更

- 增加稳定发布工作流：校验 VERSION、清单、发布说明、技能结构、测试及提交规范后创建附注 tag 和 GitHub Release。
- README 展示最新 Release，并提供稳定版安装和更新入口。
- 维护规则明确版本号、tag 与 Release 的一致性；已发布 tag 和内容保持不变，修正使用新版本。
- 源码导出包含发布说明，保持发布材料完整。

## 安装与更新

完整安装本版本及清单中的技能：

```bash
git clone --branch v0.4.3 --depth 1 https://github.com/wavachao/wava-work.git wava-work-v0.4.3
cd wava-work-v0.4.3
python scripts/install.py -y
```

Claude Code 加 `--agent claude-code`。更新至后续稳定版时查看 Releases，并使用对应 tag 检出源码后重新运行安装入口。仅更新源码不会自动更新所有客户端；ChatGPT Work 按平台方式管理技能。

## 版本与依赖策略

- Wava Work、tag 和本 Release 均对应 **0.4.3**；`main` 是持续开发分支。
- 默认 Ponytail 为安装时上游默认分支的最新核心技能，不由 Wava Work tag 锁定。
- 需要复现仓库内 Ponytail 快照时，运行 `python scripts/install.py --ponytail bundled -y`。
- 环境要求：Git、Python 3.10+、Node.js/npm；字体、LaTeX 和媒体工具按任务检查。
- 不包含后台自动更新、跨设备同步或模型训练服务。

## 验证范围

发布流程在对应提交上执行技能结构校验、清单完整性校验、单元测试和单行提交规范检查。此前无技能/旧版/精简版的单任务对照均通过相同验收；该结果不足以证明跨任务性能提升。

在线本机安装、各客户端兼容性及所有媒体任务未做全面实测，不能将结构与脚本检查视为这些能力已验证。

## 下载与回退

GitHub 提供本 tag 对应的源码 ZIP 和 tar.gz；它们是源码包，并非各平台安装程序。回退时检出所需稳定 tag 并重新安装；不会改写已发布的 tag。源码与第三方快照分别遵循仓库中的 MIT 许可和来源记录。
