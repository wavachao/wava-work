# 个人偏好

| 用途 | 默认字体 |
|---|---|
| 中文正文/标题 | 霞鹜文楷 LXGW WenKai |
| 英文正文 | Libre Baskerville |
| 英文标题/图表/表格/界面 | Inter |
| 代码/命令/日志 | JetBrains Mono |
| 数学公式 | LaTeX/MathTex，模板配套数学字体优先 |

- 按需核实LaTeX与字体；字体同时检查系统和用户安装目录，不能仅凭系统目录判断缺失。
- 缺字体优先官方来源和项目内使用；取得失败用相近字体说明，不能自动改系统默认字体。
- 混排协调视觉大小、基线、行距和字形覆盖，指定模板优先。
- 中文视频旁白默认微软云希男声（zh-CN-YunxiNeural），使用edge-tts；rate=-8%、pitch=-2Hz作为可调起点。不可用时说明，不静默回退旧系统配音；在线服务按实际授权范围使用。
- 文字自然具体简洁，删套话、机械过渡、反复总结和无信息段落。比较表格、步骤列表，短内容直接说清。
- 偏好美观、有个性、有意境；展示可大胆浪漫，工具文档清晰高效。当前参考与反馈优先。
- 内容决定布局，不强行对称、填满页面或默认卡片/渐变。字体改善排版，不能替代内容质量。
- 删除多余装饰、重复模块、泛化表达；替换换项目名也成立的文案，不用错别字或随机设计制造人味。
- 单次选择不等于长期偏好；长期反馈或稳定验证规律才进入本文件。
