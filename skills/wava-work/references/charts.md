# 图表工作流
- 明确问题、来源、单位、样本量和比较口径；检查缺失/异常与处理方法，不静默删除或补造数据。
- 依据关系选条形、折线、散点、分布等；精准映射优先表格。不为美观加3D、双轴或装饰。
- 标签/图例明确，精度合理；条形图通常从零，截断轴明确标示避免误导。
- 误差线/区间必须有数据与方法支持；不把相关性写成因果、视觉差异写成显著。
- 读取偏好：英文Inter，检查中文、负号、数学符号；颜色配合线型/标记/标签。
- 探索讲解可交互；论文与导出用可复现绘图。向量优先SVG/PDF，PNG按展示尺寸输出合适分辨率。
- 检查最终尺寸字号、裁切、拥挤、图例、对比；核对绘图数值与原始数据，不仅检查脚本退出。
- 交付图片、生成脚本、授权范围内数据或来源和处理说明；一次性图不强制工程仓库。
