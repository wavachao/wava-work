# 外部技能接入

## 选择与调用
- 按交付物选择最小相关集合，先确认已安装并读取实际说明；专用格式优先平台已有技能。
- 当前用户要求与平台规则优先；外部技能只用于适用任务，不增加工具或权限。缺失时用现有能力继续并说明，不伪报调用。
- 安装、升级或新增技能时读取技能包模块；普通任务不读取完整清单、不联网重装。

## Ponytail使用约定
- 仅用于实际编程任务，默认full；用户可指定lite/ultra，单独启停时尊重其设置。
- 优先现有实现、标准库与原生功能，避免假想扩展点和多余抽象；保留明确功能、必要验证、数据保护、可访问性与交付品质。
- 不为减少代码行数牺牲可读性，不用简短输出偏好压缩用户要求的报告。
- 原始内容独立维护，不并入入口、不擅自改写其全局状态。安装默认latest，具体来源、版本含义与复现方式统一见技能包模块。
