# 文档工作流
- 明确受众、篇幅、源文件与导出格式，优先平台documents/pdf专用技能执行制作及验证；本模块补充个人偏好与模板要求。
- 投稿、学校、公司模板高于个人偏好。LaTeX先核对实际环境的引擎与包；中文/系统字体优先可用XeLaTeX或LuaLaTeX，公式用模板配套字体。
- 读取偏好模块；正文围绕读者目标，短内容不扩写。核对作者、单位、数据与引用，不编造文献或实验。
- 实际数据图读取图表模块并保留可复现表达。
- 遵循专用技能的渲染检查；缺少专用技能时仍检查实际页面的缺字、溢出、分页、表格和引用，不以导出成功代替验收。
- 交付所需源文件与最终格式、必要编译/编辑方法，注明未验证项。
