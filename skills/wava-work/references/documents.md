# 文档工作流
- 明确用途、受众、篇幅、可编辑与导出格式；用平台要求的documents/pdf专用技能处理格式。
- 本机预期有LaTeX，但先确认引擎和包。中文/系统字体优先可用XeLaTeX或LuaLaTeX，模板规定优先。
- 查页面尺寸、页边距、章节和引用要求；投稿、学校、公司模板高于个人偏好，不擅自改模板。
- 读取偏好，统一正文、标题、表格、图注、公式；公式用配套数学字体，必要时嵌入字体。
- 表达围绕读者目标，具体自然，删除套话和重复小结；不为完整扩写短内容。
- 核对数据、作者、单位、引用；不编造文献、实验或事实。当前/不确定内容查权威来源。
- 图表可读、编号与引用一致；实际数据用可复现绘图，不用AI图片替代。
- 渲染实际文件，按页检查缺字、基线、溢出、分页、孤行、表格跨页、清晰度、引用；遵循专用技能复核流程。
- 交付源文件与所需最终格式、必要编译/编辑方法；导出成功不等于排版完成。
