# 演示工作流
- 用平台presentations技能；明确受众、演讲时长、论点、比例、格式。
- 先简短叙事顺序，一页一个主要信息，标题具体；不默认堆目录、优势、总结。
- 读取偏好：英文标题Inter，长英文可用Libre Baskerville。内容过密先改写拆页，不缩到难读字号。
- 按内容选图、流程、对照等，不每页同一卡片；风格统一，不强求对称。
- 数据图用图表模块，保留可编辑或可复现数据表达；素材有来源，缺事实明确占位。
- 需要时提供演讲备注，不把讲稿堆满页面；动画依用途和播放支持决定。
- 渲染全部页面，逐页查重叠、溢出、字号、字体替换、裁切、图表；必要时查编辑性和播放。
- 交付可编辑PPTX/指定格式、必要预览、用户要求的PDF；文件生成不等于验收。
